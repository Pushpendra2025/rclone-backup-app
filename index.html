rclone backup (personal)

A private, single-user backup setup.

This is the Google sign-in identity for one person's backup tool. It is rclone (open-source file-sync software) together with restic (open-source backup software), run by the owner on the owner's own computer.

What it does

  • Every night it stores an encrypted backup of the owner's own files in the owner's own Google Drive.
  • It asks Google for the narrowest Drive permission (drive.file). It can see and change only the files it created itself, and nothing else in the Drive.
  • Backups are encrypted on the owner's computer before upload, so the stored files can't be read without the owner's password.

Who can use it

Only its owner. It is not offered as a service, has no other users, and does not ask anyone else for access.
